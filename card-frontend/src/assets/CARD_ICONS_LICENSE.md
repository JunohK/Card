# 카드 아이콘 라이선스 (CC BY 3.0)

뱅 모드의 카드 아이콘 이미지는 [game-icons.net](https://game-icons.net) 의 SVG를 사용합니다.

**라이선스**: [Creative Commons Attribution 3.0 (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/)

## 출처 표기

사용 중인 아이콘 작가:
- **Delapouite** — https://delapouite.com (revolver, avoidance, old-wagon, shop, saloon-doors,
  machine-gun-magazine, horse-head, telescope, barrel, dynamite, sombrero, buffalo-head,
  musical-notes, metal-plate, western-hat, bookshelf 등)
- **Lorc** — https://lorcblog.blogspot.com (beer-stein, cash, cat, screaming, feather-wound,
  crossed-pistols, imprisoned, punch-blast, martini, punch 등)

전체 아이콘 모음: https://github.com/game-icons/icons

## 사용 방식

[BangPage.tsx](../pages/BangPage.tsx) 의 `CARD_IMAGES` 객체에서 jsDelivr CDN URL 형식으로 참조:
```
https://cdn.jsdelivr.net/gh/game-icons/icons@master/{author}/{name}.svg
```

CC BY 3.0 라이선스 조건상 출처 표기만 하면 상업/비상업 모두 무료 사용 가능.
